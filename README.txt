【学生信息答题系统】使用说明

========== 快速开始 ==========

1. 解压这个压缩包到你的电脑

2. 双击运行 "启动.bat" 文件

3. 在浏览器中输入以下地址：
   http://localhost:8000/quiz.html

4. 开始答题！

========== 详细说明 ==========

【如果"启动.bat"打不开】
- 右键点击"启动.bat"
- 选择"用记事本打开"
- 看看路径是否正确
- 如果有中文显示问题，试试用"修复.bat"

【在手机上使用】
- 在同一个WiFi网络中
- 用电脑IP地址打开，比如：http://192.168.1.100:8000/quiz.html
- （IP地址会在启动.bat窗口中显示）

【需要帮助】
- 确保Python已安装
- 确保文件夹"13160"存在（里面是照片）
- 重新启动一遍试试

========== 文件说明 ==========
- quiz.html - 答题页面
- 启动.bat - 启动服务器脚本
- 13160/ - 学生照片文件夹
- quiz_data.json - 学生数据

祝你答题愉快！
